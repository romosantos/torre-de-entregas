# Torre de Entregas (protótipo)

Protótipo navegável de um app de controle e monitoramento de entregas de última milha. Todos os dados são fictícios.

- `index.html`: protótipo em arquivo único. Abra no navegador, sem build.
- `dados_demo.json`: base de demonstração totalmente mascarada (nomes, NFs, rotas, placas e valores fictícios).

Telas: Torre de controle (fila de alertas e mapa), Rotas, Ocorrências, Liberação (validação por NF), Passagem de turno, Relatório do dia e App do motorista.
